HTTPS for *.nghodki.ai

Install this once per device. It only lets your device trust nghodki.ai sites; it can't vouch for any other website.

iPhone / iPad

Download profile

  1. Open it in Safari and tap Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on nghodki homelab web CA.

Mac

Download certificate

  1. Open the file; it goes into Keychain Access (System).
  2. Double-click nghodki homelab web CA → Trust → Always Trust.

Android

Download certificate

Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate. (Menu names vary by phone.)

Windows

Download certificate → Install Certificate → Local Machine → Trusted Root Certification Authorities.

Then open https://webui.nghodki.ai. No warning means it worked.
